# Phishing Awareness Simulation

A simple cybersecurity project developed using Python to teach users how to identify common phishing warning signs.

## Features

- Shows an example suspicious email
- Identifies common phishing warning signs
- Checks for urgency in messages
- Checks suspicious sender addresses
- Teaches users to verify links
- Provides a simple awareness score

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python phishing_awareness_simulator.py
